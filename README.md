# Hakai Pass 2026 — crew site

Temporary site for our August 2026 trip crew: the field guide, the grounds map, and the pre-trip Film Room.
Not affiliated with or endorsed by Joe's Salmon Lodge; photos are from the lodge's public Instagram (@onlyatjoes) and belong to the lodge and its guests.

This site comes down after the trip. Takedown:

```bash
gh api -X DELETE repos/mr-mcateer/hakai-2026/pages   # take the site offline
gh repo archive mr-mcateer/hakai-2026 -y             # freeze the repo
```
